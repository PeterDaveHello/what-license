# Changelog

## v0.1.0

- Rebuilt the app with Vite, TypeScript, Tailwind CSS, and vanilla DOM rendering.
- Replaced the hidden-DOM license store with a generated SPDX license-list-data snapshot.
- Added strict and loose normalization, SPDX identifier detection, shingle F1 ranking, input classification, and GNU only/or-later safeguards.
- Added a modern browser-only UI with samples, paste, clear, drag-and-drop, copyable SPDX IDs, confidence labels, input type labels, and top-three diff summaries.
- Added Vitest unit coverage, Playwright smoke coverage, license data verification, linting, build checks, CI, and GitHub Pages deployment workflow.

## Before v0.1.0

- CoffeeScript prototype with handwritten license fixtures and diff-based ranking.
